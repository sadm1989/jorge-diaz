El Dashboard (la pantalla principal)
Pipeline activo La plata total que podrías ganar
Ver →
Pipeline activo es la suma de todos los montos de las licitaciones que el sistema detectó para Recasur y que aún están abiertas. Es el máximo que podrías ganar si ganaras todas — en la práctica ganarás una parte de eso.
Si el pipeline dice $784M CLP, significa que hay licitaciones abiertas por ese total. No es plata en el bolsillo todavía — es plata posible.
No te frustres si el número baja — significa que algunas licitaciones cerraron o se ganaron. Lo importante es que siempre haya licitaciones entrando.
Score (0–100) Qué tan buena es la licitación para Recasur
Ver →
El score es el número que el sistema le da a cada licitación del 0 al 100. Mide qué tan buena es esa licitación específicamente para Recasur considerando: el rubro, el cliente, la región y el monto. Más alto = más conveniente postular.
Score 96 = excelente (postular sí o sí). Score 41 = malo (no vale la pena). Score 65 = revisar antes de decidir.
El score lo calcula el sistema automáticamente. Tú solo debes seguir la decisión recomendada que aparece en verde o rojo.
Oportunidades hoy Las licitaciones filtradas para Recasur
Ver →
Cada mañana el sistema revisa todas las licitaciones publicadas en Chile ese día (pueden ser cientos). Filtra solo las que tienen productos o clientes que Recasur vende. El número que ves es cuántas pasaron ese filtro.
Si dice "23 oportunidades hoy" — de 370 licitaciones publicadas en Chile hoy, 23 son para Recasur.
Las que no aparecen no son para Recasur — el sistema ya las descartó para no hacerte perder tiempo.
Tasa de éxito De cada 10 que postulas, cuántas ganas
Ver →
La tasa de éxito (o tasa de adjudicación) es el porcentaje de licitaciones que Recasur gana de las que postula. Si dice 43% significa que de cada 10 licitaciones en que se postula, se ganan aproximadamente 4.
El promedio del mercado chileno es 24%. Si Recasur tiene 43% significa que Jorge está trabajando mejor que la mayoría de los vendedores.
Esta es la estadística más importante para mostrarle a Jorge Guic — demuestra que la gestión de Jorge Díaz genera resultados reales.
Las tarjetas de licitación
Postular sí o sí Licitación de alta prioridad, acción inmediata
Ver →
El sistema detectó que esta licitación tiene score alto, rubro fuerte y cliente conocido. La probabilidad de ganar es alta. No hay razón para no postular — solo hay que confirmar stock y preparar la propuesta.
Una licitación de INDESPA en Magallanes para equipos de buceo = "Postular sí o sí". Es el rubro más fuerte de Recasur, el cliente más frecuente y está en tu territorio.
Postular si hay stock Buena licitación, pero verificar primero
Ver →
La licitación es buena, pero antes de comprometerse hay que revisar si Recasur tiene el producto en bodega. Si hay stock → postular. Si no hay stock → pedir cotización a proveedor antes del cierre.
Una licitación de chalecos salvavidas para la Municipalidad. Conviene, pero primero verificar cuántos chalecos hay disponibles en bodega.
Revisar margen Antes de postular, calcular si vale la pena
Ver →
El sistema detectó que esta licitación tiene algo que hay que revisar antes de postular — puede ser que el rubro sea difícil, que Dimarsa compita, o que el margen de ganancia sea incierto. No descartar, pero tampoco postular a ciegas.
Una licitación de radios VHF/UHF. Recasur tiene poca experiencia en comunicaciones. Antes de postular: ¿tenemos los equipos exactos? ¿cuánto nos cuesta conseguirlos? ¿hay margen de ganancia?
Pedir cotización Consultar precio al proveedor antes de decidir
Ver →
Recasur no fabrica los productos — los compra a proveedores y los revende al Estado con un margen de ganancia. Pedir cotización significa contactar al proveedor para saber cuánto le cuesta el producto, y así calcular si hay ganancia real en la licitación.
Una licitación pide GPS marinos. Recasur llama a su distribuidor de Garmin, pide precio, calcula: "Si el Estado paga $42M y el proveedor me cobra $35M, gano $7M." ¿Vale el trabajo? Sí → postular.
No pierdas tiempo aquí Esta licitación no conviene
Ver →
El sistema detectó que esta licitación tiene score bajo — puede ser porque está fuera de Magallanes, el monto es pequeño, el rubro es difícil, o el cliente nunca ha comprado a Recasur. El tiempo que tomaría preparar la propuesta es mejor invertirlo en las licitaciones con score alto.
Una licitación de lubricantes en Valparaíso por $18M. Fuera de región + rubro débil + monto pequeño = el sistema dice "no pierdas tiempo". Ese tiempo es mejor dedicarlo a la licitación de INDESPA por $185M.
Descartar licitaciones malas es tan valioso como ganar licitaciones buenas. Protege tu tiempo y el margen de Recasur.
Días al cierre Cuánto tiempo queda para postular
Ver →
Cada licitación tiene una fecha de cierre — el día en que el organismo público deja de recibir propuestas. Si dice "8 días", tienes 8 días para preparar y enviar tu propuesta. Después de esa fecha no puedes postular aunque quieras.
Cierra en 3 días → acción urgente hoy mismo. Cierra en 20 días → tiempo suficiente para preparar bien la propuesta.
El sistema te avisa con anticipación para que nunca pierdas una licitación por llegar tarde.
Riesgo alto / medio / bajo Cuántos problemas puede tener esta licitación
Ver →
El riesgo operativo mide qué tan complicado puede ser cumplir con lo que pide la licitación. Incluye: si las bases son muy exigentes, si hay garantías que depositar, si el plazo de entrega es muy corto, o si el rubro es uno donde Recasur ha perdido antes.
Riesgo bajo: licitación de chalecos salvavidas para la Municipalidad de Punta Arenas. Recasur tiene el producto, el cliente es conocido, el plazo es razonable.

Riesgo alto: licitación de radios VHF para la Armada. Rubro difícil, bases técnicas complejas, competidores fuertes, Recasur tiene poca experiencia ahí.
Riesgo alto no significa descartar automáticamente — significa revisar con mucho cuidado antes de comprometer recursos.
Margen alto / medio / bajo Cuánto gana Recasur si adjudica
Ver →
El margen es la diferencia entre lo que el Estado paga y lo que le cuesta el producto a Recasur. Es la ganancia real del negocio.
El Estado paga 2M por GPS marinos. Recasur los consigue del proveedor en 5M. El margen es M (16%). ¿Es bueno? Depende del trabajo que implica.

Margen alto: más del 20%. Margen medio: 10–20%. Margen bajo: menos del 10% — ojo, puede que no valga el esfuerzo.
Si el margen es desconocido — el sistema dice "pedir cotización" primero para calcularlo antes de comprometerse.
Probabilidad de ganar Qué tan probable es que Recasur adjudique
Ver →
El sistema estima la probabilidad de ganar basándose en: historial con ese cliente (¿Recasur le ha vendido antes?), región (¿es Magallanes donde hay ventaja logística?), competidores detectados y rubro (¿fuerte o débil?).
Alta: INDESPA Magallanes en náutico — cliente frecuente, región con ventaja, rubro fuerte.
Media: Carabineros en GPS marinos — cliente conocido pero rubro difícil.
Baja: organismo nuevo fuera de región en rubro débil.
Probabilidad alta + margen alto = postular sí o sí. Probabilidad baja + margen bajo = no pierdas tiempo.
Fit comercial Qué tan bien calza la licitación con Recasur
Ver →
El fit comercial mide qué tan bien encajan los productos que pide la licitación con lo que Recasur vende normalmente. Si es rubro fuerte (náutico, salvamento) el fit es alto. Si es rubro débil (lubricantes, comunicaciones) el fit es bajo.
Licitación de equipos de buceo = fit comercial 90/100. Recasur vende esto hace años, tiene proveedores, conoce el producto.

Licitación de software informático = fit comercial 0/100. Recasur no vende software.
Valor económico Qué tan atractivo es el monto de la licitación
Ver →
Mide si el monto de la licitación justifica el tiempo de preparar la propuesta. Una licitación de M requiere casi el mismo trabajo que una de 00M — pero la ganancia es muy diferente. El sistema da más valor a montos que están en el "sweet spot" de Recasur: entre 0M y 00M CLP.
Licitación de 85M = valor económico alto. Licitación de M = valor económico bajo (¿vale la pena el trabajo?).
Orden de Compra (OC) El documento con el que el Estado paga
Ver →
Cuando Recasur gana una licitación, el organismo público emite una Orden de Compra. Es el documento oficial que autoriza el pago. Una vez que Recasur recibe la OC, entrega el producto y puede cobrar.
INDESPA adjudica la licitación a Recasur → emite OC por 8.200.000 → Recasur entrega los equipos de buceo → INDESPA paga dentro del plazo estipulado (generalmente 30 días).
El sistema monitorea las órdenes de compra de organismos frecuentes para detectar patrones de compra recurrente.
Bases administrativas / técnicas Las reglas del juego de cada licitación
Ver →
Cada licitación viene con documentos que explican todo: qué producto exactamente se necesita, qué requisitos debe cumplir la empresa, qué documentos hay que presentar, cómo se evalúan las propuestas y qué pasa si no se cumple lo prometido.

Bases administrativas: los requisitos legales y de la empresa (RUT, documentos, garantías).
Bases técnicas: las especificaciones exactas del producto (modelo, tamaño, certificaciones).
Las bases técnicas dicen "chaleco clase V homologado DIRECTEMAR". Si el chaleco de Recasur no tiene esa certificación, la propuesta queda inadmisible (descartada aunque sea la más barata).
SIEMPRE leer las bases antes de postular. Una propuesta que no cumple los requisitos se descarta automáticamente — da igual el precio que ofrezca.
Inadmisible La propuesta fue rechazada por incumplir requisitos
Ver →
Una propuesta inadmisible es aquella que el organismo rechazó porque no cumplió algún requisito de las bases — puede ser que faltó un documento, que el producto no tenía la certificación correcta, o que la garantía fue insuficiente. La propuesta se descarta sin importar el precio.
Recasur postula una licitación pero olvida adjuntar el certificado de la Cámara de Comercio. Aunque ofrezca el precio más bajo, queda inadmisible. No gana nada y pierde el tiempo de preparación.
Por eso el sistema incluye "documentos pendientes" en cada tarjeta — para recordar qué hay que adjuntar antes de postular.
Garantía de seriedad Un depósito que se hace al postular licitaciones grandes
Ver →
En licitaciones grandes, el organismo exige que las empresas depositen una garantía de seriedad de oferta — puede ser un boleto de garantía del banco o una póliza de seguro. Es para asegurar que si Recasur gana, cumple con entregar.
Una licitación por 85M puede exigir una garantía de .850.000 (1% del monto). Si Recasur gana y no entrega, pierde esa garantía. Si no gana, se le devuelve.
Verificar siempre si la licitación exige garantía. Si sí, hay que tramitarla en el banco antes de la fecha de cierre.
Competidores y alertas
Alerta Dimarsa El competidor más peligroso está participando
Ver →
Dimarsa es el competidor más agresivo de Recasur en el rubro náutico. Fabrican sus propias embarcaciones HDPE, tienen precios muy bajos y son distribuidores oficiales de marcas importantes. La alerta roja significa que Dimarsa detectado participando en esa licitación específica.
Si Dimarsa participa en una licitación de botes HDPE, probablemente va a ofrecer el precio más bajo porque los fabrica ellos mismos. Recasur no puede ganar compitiendo por precio ahí.
Estrategia contra Dimarsa: no competir por precio. Ganar con: entrega en 48h desde Punta Arenas, técnico disponible en Magallanes, garantía con servicio local. Dimarsa opera desde Puerto Montt — no tiene nadie en Punta Arenas.
Ventaja Magallanes Por qué estar en Punta Arenas es una ventaja enorme
Ver →
Recasur tiene sede en Punta Arenas. Todos los competidores importantes (Dimarsa, Salfa, Kauffman) tienen sede en Puerto Montt o Santiago — a más de 2.000 km. Eso significa que Recasur puede entregar productos en 24-48 horas, mientras la competencia tarda días o semanas y tiene costos de flete enormes.
El Gobierno Regional de Magallanes necesita chalecos salvavidas urgente. Recasur entrega mañana desde su bodega en Punta Arenas. Dimarsa tarda 5-7 días desde Puerto Montt con flete a la Patagonia.
En licitaciones de Magallanes, siempre mencionar en la propuesta: stock disponible en Punta Arenas + entrega inmediata + técnico local. Eso vale más que el precio más bajo.

Revisando bases Leyendo los documentos de la licitación
Ver →
Las bases son los documentos oficiales que publica el organismo público con todas las reglas de la licitación: qué productos exactos necesitan, qué requisitos debe cumplir la empresa, qué documentos hay que presentar, cómo se evalúan las propuestas. Hay que leerlas antes de postular.
Las bases dicen "chaleco salvavidas clase V homologado por la Marina". Si Recasur no tiene ese modelo específico, no puede postular aunque tenga chalecos.
Cotizando proveedor Pidiendo precio al proveedor antes de postular
Ver →
Se está esperando que el proveedor informe cuánto cuesta el producto. Con ese precio se puede calcular cuánto ganará Recasur si adjudica la licitación.
Postulada La propuesta ya fue enviada, esperando resultado
Ver →
La propuesta de Recasur fue enviada al organismo público. Ahora hay que esperar que el organismo evalúe todas las propuestas recibidas y adjudique a alguna empresa.
El tiempo de evaluación puede ser desde 3 días hasta 2 meses dependiendo de la licitación. El sistema te avisa cuando hay un resultado.
Adjudicada ✓ ¡Recasur ganó la licitación!
Ver →
Adjudicar significa ganar una licitación. El organismo público eligió la propuesta de Recasur y ahora debe emitir una Orden de Compra. Una vez recibida la OC, Recasur entrega el producto y cobra.
La adjudicación aparece publicada en mercadopublico.cl. El sistema la detecta automáticamente y actualiza el reporte mensual.
El Reporte Ejecutivo
Reporte ejecutivo El documento mensual para mostrarle al jefe
Ver →
El reporte ejecutivo es un documento de 4 páginas que resume todo lo que Jorge Díaz gestionó durante el mes: cuántas licitaciones detectó, cuántas ganó, cuánto dinero representa, cómo actuó frente a Dimarsa. Está diseñado para presentárselo a Jorge Guic (el dueño de Recasur).
El reporte está pensado para que Jorge Díaz pueda demostrar su valor dentro de la empresa y justificar mejores condiciones laborales o comisiones.
Monto adjudicado La plata real que Recasur ganó este mes
Ver →
Es la suma de todas las licitaciones que Recasur ganó durante el mes. Esta sí es plata real — no potencial. El Estado ya adjudicó y Recasur debe entregar los productos para cobrar.
Si el reporte dice "$168M adjudicados en abril", significa que el Estado le compró $168 millones en productos a Recasur ese mes.
Decisiones inteligentes Las licitaciones que se descartaron a propósito
Ver →
No solo importa lo que se ganó — también importa lo que se descartó con criterio. Cada licitación mala que se descarta es tiempo y recursos que se pueden invertir en las buenas. El reporte muestra esto porque es parte del valor que Jorge Díaz aporta a Recasur.
"Se descartó Vialidad Valparaíso ($18M, fuera de región) para invertir ese tiempo en INDESPA Magallanes ($185M). Resultado: se ganó INDESPA." Eso es gestión inteligente.
